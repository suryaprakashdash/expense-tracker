#Personal Expense Tracker

A simple command-line Expense Tracker built using Python to manage daily expenses and track spending. This project is created to practise Python programming concepts through a real-world application.

Features

- Add new expenses
- View all recorded expenses
- Calculate total expenses
- Search expenses by category
- Delete expenses
- Store expense details using a list
- Interactive menu-driven interface

Technologies Used

- **Programming Language:** Python 3
- **Interface:** Command-Line Interface (CLI)

Python Concepts Used

- Variables and data types
- Operators and type conversion
- Conditional statements (`if-elif-else`)
- Loops (`for` and `while`)
- Lists and list methods
- Functions
- Exception handling
- Built-in functions
